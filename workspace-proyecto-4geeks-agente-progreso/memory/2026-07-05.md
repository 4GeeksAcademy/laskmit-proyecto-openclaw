  "account": "accounts/default"
}

### Lecciones aprendidas
1. `GOOGLEDRIVE_COPY_FILE` con `parents` como string vs array — usar string
2. `GOOGLEDOCS_CREATE_DOCUMENT_MARKDOWN` a veces crea docs vacíos; fallback: CREATE vacío + UPDATE con markdown
3. `GOOGLEDOCS_UPDATE_DOCUMENT_MARKDOWN` con markdown que tiene tablas SÍ funciona (reporta `replies.length`)
4. Para que URLs sean clickables en Google Docs, **TODAS deben ir en formato `[url](url)`** — URLs como texto plano NO se convierten
5. Al crear doc vía trabajo en workbench de Composio, codificar el markdown en base64 y escribirlo como archivo local primero, luego leer desde ahí
